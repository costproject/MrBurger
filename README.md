# Mr. Burger 🍔💻

**Burger Shop Management System – Built with Java & MySQL**

Mr. Burger is a full-featured desktop application designed to streamline operations for a burger shop. This software was developed by a team of four as part of our coursework at the University of Kelaniya, Sri Lanka. The system aims to improve customer service, order accuracy, and stock management through a secure, user-friendly interface.

## 🚀 Key Features

- **Secure Cashier Login**  
  Each cashier is assigned a unique username and password for secure access to the system.

- **Real-Time Burger Inventory**  
  Cashiers can view available burger varieties, quantities, and details instantly.

- **Customer Registration & Management**  
  Simple customer registration with auto-generated unique IDs. Cashiers can also update customer details easily.

- **Order & Billing System**  
  Orders are placed using customer IDs. Automatic bill generation and printing are triggered upon payment.

- **Discount Handling**  
  Cashiers can apply discounts during checkout for flexible pricing.

- **Stock & Price Management**  
  Admin-level access to update burger prices, stock quantities, and product information.

- **Order History & Customer Insights**  
  Full visibility into previous orders and customer profiles, without manual database queries.

## 🛠️ Tech Stack

- **Programming Language:** Java  
- **Database:** MySQL  
- **Development Methodology:** Object-Oriented Programming (OOP)  
- **IDE:** NetBeans / IntelliJ IDEA  
- **Version Control:** Git, GitHub

## 📌 Project Goals

- Improve operational efficiency at burger shops
- Provide fast, accurate customer service
- Maintain organized and up-to-date stock records
- Reduce manual billing errors through automated processing
